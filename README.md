# Cancer Risk Diagnosis using ANNs (TensorFlow)

ANN classifier for cancer risk level (Low/Medium/High) using the Kaggle
"Cancer Patients Data" dataset by Rishi Damarla.

## Run
pip install tensorflow pandas openpyxl scikit-learn matplotlib
python ann_cancer_diagnosis.py

## Files
- ann_cancer_diagnosis.py: full pipeline
- cancer_patient_data_sets.xlsx: dataset
- results.json and figures/: evaluation results
